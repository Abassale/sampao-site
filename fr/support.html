Questions fréquentes

Faut-il un compte ?

Non. Aucun compte joueur n'est requis.

Où sont les sauvegardes ?

La progression et les records sont enregistrés localement via Capacitor Preferences. Il n'y a pas de sauvegarde cloud. Désinstaller le jeu peut effacer la progression.

Les publicités et Premium sont-ils actifs ?

Non. Les annonces sont désactivées dans cette version TestFlight. L'achat Premium n'est pas encore commercialement actif. Tous les niveaux sont accessibles gratuitement.

Comment signaler un plantage ?

Envoyez vos commentaires via TestFlight ou par e-mail avec le modèle d'appareil, la version iOS et les étapes de reproduction.

Comment supprimer mes données ?

Supprimer l'application efface normalement les données locales, sous réserve des sauvegardes iOS. Contactez l'assistance pour obtenir de l'aide.
